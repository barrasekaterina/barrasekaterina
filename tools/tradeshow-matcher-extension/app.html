How field detection works

  • Full Name is the only required column.
  • Any of Company Name, Phone, Email that are present and non-empty are used as extra matching signals, in any combination.
  • A tradeshow record is only reported as a match when the name matches and at least one other available field also matches.
  • This extension itself can't open a direct SQL Server connection (no browser can) — "Pull live" sends your request to the local Flask backend from the Python version of this tool (tools/tradeshow-matcher), which must already be running on this machine and does the real database connection via Windows Integrated Auth.
